# 九维度扫描速查表

第 2 步并行扫描时按表逐项过。每项只收集候选，不判定。

## 1. 注入类
- 盯：字符串拼接/格式化构造 SQL、shell 命令、LDAP、XPath、模板。
- 信号：`%`/`format`/f-string 进 `execute(`；`shell=True`；`os.system`/`popen` 拼输入；模板引擎渲染用户输入。
- 先记候选，后续验证是否有参数化/转义拦住。

## 2. 认证与会话
- 盯：登录、会话、token、OAuth 回调、密码重置流程。
- 信号：无登录失败限流；会话 ID 可预测；`state` 参数不校验；重置 token 长期有效；JWT 不验签名/过期。

## 3. 密钥与敏感信息
- 盯：硬编码密钥/token/口令；日志、报错、URL 里带敏感信息；弱随机数做安全用途。
- 信号：`API_KEY = "..."`；`log.info(password)`；`random.random()` 生成 token（应为 `secrets`）。

## 4. 访问控制
- 盯：每个敏感操作前的权限检查；对象级授权。
- 信号：按 ID 查资源但不校验归属（IDOR）；管理接口无鉴权；"默认允许"逻辑。

## 5. 不安全默认
- 盯：框架/服务的默认配置。
- 信号：`debug=True` 上线；默认口令未改；CORS `*` 带凭证；目录浏览开启；错误堆栈直接返回给用户。

## 6. 密码学
- 盯：算法选择、密钥管理、传输校验。
- 信号：MD5/SHA1 存口令（应为 bcrypt/argon2）；DES/RC4/ECB；自造加密；`verify=False`；硬编码 IV；密钥与密文放一起。

## 7. 供应链
- 盯：依赖与构建。
- 信号：无锁文件；依赖版本有已知 CVE（可联网搜索核验）；构建/安装脚本执行远程拉取的代码；包来源非官方源。

## 8. 内存与并发
- 盯：（C/C++/Go/Rust 等）越界、UAF、数据竞争、TOCTOU。
- 信号：裸指针运算；`unsafe` 块；共享变量无锁；先检查后使用（check-then-act）跨越信任边界。

## 9. 危险 API 设计
- 盯：把危险操作包装成"方便"接口，调用方极易误用。
- 信号：`query(sql_string)` 直接拼 SQL；`read_file(path)` 无路径校验；`run(code)` 反射执行；"万能管理函数"。
